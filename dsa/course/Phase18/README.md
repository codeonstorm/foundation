# Phase 18: Math For DSA In Java

Welcome to Phase 18 of your DSA course. This phase teaches the math tools that appear often in coding interviews and competitive programming.

The goal is not to become a mathematician. The goal is to recognize when a problem is really about divisibility, primes, modular arithmetic, counting, or numeric representation.

## What You Will Learn

- Prime numbers
- Sieve of Eratosthenes
- GCD and LCM
- Euclidean algorithm
- Modular arithmetic
- Fast exponentiation
- Factorials
- Permutations and combinations
- Modular inverse basics
- Pigeonhole principle basics
- Count primes
- Pow(x, n)
- Trailing zeroes
- Happy number
- Excel column number
- nCr modulo prime
- Handling overflow and modulo constraints

## Learning Goal

By the end of this phase, you should be able to:

- Check primes efficiently.
- Generate primes with a sieve.
- Use GCD and LCM safely.
- Avoid integer overflow with `long`.
- Apply modulo rules correctly.
- Compute powers in `O(log n)`.
- Calculate combinations under a prime modulo.
- Recognize common math patterns in DSA problems.
